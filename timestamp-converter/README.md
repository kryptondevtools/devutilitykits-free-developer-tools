## What is a Unix timestamp?

A Unix timestamp represents a point in time as the number of seconds or milliseconds relative to the Unix epoch, traditionally 1970-01-01 00:00:00 UTC.

## Common uses

- Debugging API responses
- Reading database timestamps
- Working with logs
- Converting epoch values
- Checking expiration times
- Comparing dates across systems

## Seconds vs milliseconds

Many systems use seconds while JavaScript and some APIs commonly use milliseconds. Always confirm the unit before converting a timestamp.

## Time zones

Unix timestamps represent an instant in time. When displaying the result to a person, the selected time zone affects the displayed calendar date and clock time.
