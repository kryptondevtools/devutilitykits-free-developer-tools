# Contributing to DevUtilityKits

Thanks for your interest in improving DevUtilityKits.

## Ways to contribute

You can contribute by:

- Improving documentation
- Adding practical examples
- Reporting incorrect behavior
- Suggesting useful developer workflows
- Improving accessibility
- Fixing bugs
- Improving test coverage

## Before opening an issue

Please check existing issues first. For a bug report, include:

1. What you expected to happen
2. What actually happened
3. Steps to reproduce the problem
4. Browser and operating system when relevant
5. A small example input when possible

Do not include passwords, API keys, private tokens, personal information, or other sensitive data.

## Pull requests

Keep pull requests focused on one change when possible.

For documentation changes:

- Keep examples accurate
- Prefer concise explanations
- Use Markdown headings consistently
- Check links before submitting

For code changes:

- Explain the change
- Include tests when appropriate
- Avoid unrelated formatting changes
