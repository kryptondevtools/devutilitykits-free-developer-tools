# Base64 Tools

Encode and decode Base64 data with DevUtilityKits.

**Online tools:** https://devutilitykits.com/categories/encoding-and-conversion

## Common uses

Base64 is commonly encountered when working with:

- API payloads
- Authentication headers
- Data URLs
- Embedded images
- Configuration values
- Encoded text
- Web development workflows

## Encode

Convert ordinary text or supported input into Base64 representation.

## Decode

Convert Base64 data back into its original supported representation.

## Important

Base64 is an encoding format, not encryption. Do not treat Base64 as a security mechanism for protecting secrets.
