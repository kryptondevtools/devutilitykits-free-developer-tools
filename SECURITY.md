# Security Policy

## Reporting a security issue

Please do not publish sensitive security details in a public issue.

When reporting a potential security problem, provide:

- A short description
- The affected tool or repository path
- Steps to reproduce
- The potential impact
- A minimal proof of concept when safe

Remove credentials, API keys, personal information, and other secrets before sharing.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing a security vulnerability.

## Privacy

Never submit real passwords, private keys, authentication tokens, or confidential production data to public issue trackers or example files.
